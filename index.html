About

Security that can prove itself

I am the co-founder and Chief Security Officer of Zagreus AI (formerly Beat.AI), a startup building a multi-tenant AI platform that automates work across enterprise systems. I lead the security program end to end: architecture, identity and access, monitoring, incident response, secure development and compliance documentation.

My rule is simple: a control that is deployed is not a control that is verified. Every change I approve needs a positive test, a negative test and dated evidence before it counts as done.

Before cybersecurity I spent fifteen years in manufacturing, starting as a machine operator and growing into leading teams in a regulated, safety-first environment. That background shapes how I work today: clear procedures, measurable results and people who know exactly what to do when something goes wrong.

I am completing a B.S. in Cybersecurity and Networking at DeVry University, and I enjoy helping other students find their way into this field.

Work at Zagreus AI

What I build as CSO

Security for a multi-tenant AI platform, built by a small team. Described in general terms; specific designs and findings stay confidential.

Governance

A security program from zero

Built the full program: risk register and plan of action, policies, standards and an evidence process, mapped to NIST SP 800-53 for a federal authorization path.

Architecture

Tenant isolation

Designed and built the first isolated customer environment, with separate identity, data and network boundaries, and proved isolation with positive and negative tests.

Detection

Centralized monitoring

Stood up a central SIEM with log pipelines from every environment and custom detection rules, so security events reach one place within seconds.

Tooling

A security operations console

Built an internal console that combines security checks, alerts, incident cases and compliance evidence, so one person can run the program.

Incident response

Same-night recovery

Led the investigation and recovery of a production data-loss event, restored the service the same night and documented the root cause and fixes.

Secure development

Security review before production

Review code changes for security before they ship, verify claims against the real code and require evidence before a fix is accepted.
